# 調研與競品分析指南（Phase 1）

## 1.1 查閱比賽文件

**輸入**：比賽名稱或官網 URL。
**輸出**：結構化的競賽資訊表。

執行步驟：

1. **網頁搜尋**：搜尋「`<比賽名稱> 報名簡章`」、「`<比賽名稱> 歷屆得獎`」。
2. **抓取簡章頁面**：找出官網上的簡章 URL，優先使用 `tools/fetch-and-convert.py` 抓取：
   ```bash
   # 抓取競賽簡章頁面（HTML 或 PDF），轉換為 Markdown
   python ~/.claude/skills/ai-apply/tools/fetch-and-convert.py <簡章 URL>

   # 若要存成檔案
   python ~/.claude/skills/ai-apply/tools/fetch-and-convert.py <簡章 URL> --output /tmp/guidelines.md
   ```
   - **工具失敗（exit code 1）時**：fallback 到 WebFetch 工具讀取網頁，或提示使用者手動提供簡章內容。
   - **PDF 格式**：工具會自動偵測並嘗試文字擷取。若 `pdfminer.six` 未安裝，工具會提示安裝指令並輸出錯誤。
3. **資訊萃取**：建立競賽資訊表（見 TEMPLATES.md 中的「競賽資訊表」）。


## 1.2 競品分析

**輸入**：產品名稱與定位。
**輸出**：競品比較表 + 差異化策略。

執行步驟：

1. **搜尋直接競品**：用產品核心功能關鍵字搜尋。
2. **搜尋歷屆得獎作品**：搜尋「`<比賽名稱> <年份> 得獎名單`」。
3. **建立比較矩陣**：涵蓋核心定位、技術差異、價格、目標用戶（見 TEMPLATES.md）。
4. **輸出得獎策略**：根據評分標準，對應我方產品的優勢與需補強之處。

## 1.3 資訊盤點與參賽方向

**輸入**：現有產品資料（GitHub、網站、過往比賽經驗）。
**輸出**：參賽方向建議書（1 頁）。

檢查清單：
- [ ] 公司/團隊基本資料（名稱、統編、成立日期）
- [ ] 產品網站與域名
- [ ] GitHub Repository（加分項）
- [ ] LinkedIn 團隊檔案（加分項）
- [ ] Crunchbase / 其他平台登錄（加分項）
- [ ] 過往比賽成績（如：進入決賽、獲獎紀錄）
- [ ] 市場數據與引用來源
- [ ] 技術驗證數據（準確度、成本、效能）
